# lwc-soql-builder の機能の引き継ぎ

lwc-soql-builder の機能を、sfbench で実装したかどうかを管理する一覧である。
旧版のコード（lwc-soql-builder の `src/modules/cmp/` と `src/modules/store/`）から洗い出した。
実装したら `[x]` にする。
「（新規）」は旧版になく sfbench で足す機能、「（変更）」は旧版から振る舞いを変える機能である。
引き継がない機能は末尾に理由とともに書く。

## オブジェクトの一覧（旧版 `sobjectsPanel`）

- [ ] 組織のオブジェクトをラベルと API 名で一覧する
- [ ] ラベルまたは API 名の一部で絞り込む
- [ ] 絞り込みの文字をクリアするボタン
- [ ] オブジェクトを選ぶと、項目の一覧に切り替わり、エディタに `SELECT Id FROM <オブジェクト>` が入る
- [ ] 一覧を再読み込みする（新規）

## 項目の一覧（旧版 `fieldsPanel`、`fieldsTree`）

- [ ] オブジェクトの一覧に戻るボタン
- [ ] 「Fields」と「Child Relationships」のタブ
- [ ] ラベルまたは API 名の一部で絞り込む。絞り込みは最上位の項目だけに効く。クリアするボタン
- [ ] 各項目に、ラベル、API 名、型を表示する
- [ ] メニュー: すべての項目を選ぶ（SELECT 句を項目の一覧で置き換え、親の項目とサブクエリは消える）、すべての選択を外す（`Id` だけにする）、API 名の昇順、降順で並べる
- [ ] 項目を押すと SELECT 句に追加、もう一度押すと外す
- [ ] 参照項目を展開して、親オブジェクトの項目を選ぶ。親をたどれるのは5階層まで（SOQL の制限）で、それを超えると案内を出す
- [ ] ポリモーフィックな参照項目は、参照先の最初のオブジェクト（`referenceTo[0]`）だけを展開する（旧版の仕様をそのまま引き継ぐ）
- [ ] 項目を再読み込みする（新規）

## 子リレーションの一覧（旧版 `relationshipsTree`）

- [ ] 子リレーションを、子オブジェクトの API 名とラベルと一緒に一覧する
- [ ] 絞り込む
- [ ] 子リレーションの名前を押すと、`(SELECT Id FROM <リレーション>)` のサブクエリを追加する。もう一度押すと外す
- [ ] 子リレーションを展開して、その項目をサブクエリに追加する

## エディタ（旧版 `queryEditorPanel`）

- [ ] SOQL を書くエディタ
- [ ] エディタの SOQL を解析できると、項目の一覧の選択状態が追従し、左の一覧が FROM のオブジェクトに切り替わる。エディタを空にすると、オブジェクトの一覧に戻る（旧版 `UPDATE_SOQL`）
- [ ] 実行（Query）
- [ ] 削除済みも含めて実行（Query All）
- [ ] 整形（Format SOQL）
- [ ] 補完: 項目を API 名またはラベルで探して挿入する。挿入する名前からは名前空間を省く（名前空間を省く設定がオンのとき）
- [ ] 補完: SOQL のキーワードを挿入する
- [ ] 補完は入力に合わせて開くほか、Ctrl+Space でも開く。↑↓、Enter、Esc、クリックで操作する
- [ ] 日本語入力の変換中は、Enter で補完を確定しない
- [ ] 管理パッケージの名前空間を省略して書ける（`Sforce-Call-Options: defaultNamespace`）。SOQL の生成と補完で名前空間を省く。一覧の表示は名前空間付きのまま
- [ ] 名前空間を省く機能を、設定でオフにできる（新規）
- [ ] Tooling API で実行する（新規）

## 最近のクエリ（旧版 `queryListPanel`）

- [ ] 実行に成功したクエリを新しい順に残す。同じクエリは先頭に移す（変更: 旧版は全組織共通で20件、sfbench は組織ごとに100件）
- [ ] 押すとエディタに読み込む。読み込むと、エディタの書き換えと同じく左の一覧が切り替わる
- [ ] AI に頼んだ文をクエリと一緒に表示する（新規、区切り3）

## 結果（旧版 `outputPanel`、`outputTable`、`outputCell`）

- [ ] 総件数を表示する
- [ ] 列は、SELECT 句ではなく、取得した全レコードのキーを集めて作る。親リレーションの項目は `Account.Name` のような列に展開する。集計関数の `expr0` などにも対応する
- [ ] 子リレーションのセルには件数を表示し、押すと子レコードの表を開く。閉じるボタン。新しく実行すると子レコードの表は閉じる
- [ ] スクロールに合わせて行を追加で描画し（旧版は200行ずつ）、続きのページ（`nextRecordsUrl`）を取得する
- [ ] 18桁のレコード ID を Salesforce のレコードへのリンクにする（変更: `sf org open` でログイン済みの状態で開く）
- [ ] CSV 出力。続きのページも全件取得し、BOM 付きで、カンマ、改行、二重引用符を含む値を引用符で囲む。ファイル名は `<オブジェクト>.csv`。子リレーションのセルは件数（`N rows`）を出力する
- [ ] 実行エラーを表示する

## 全体

- [ ] API 使用量を表示する
- [ ] 読み込み中の表示
- [ ] エラーの通知（旧版 `toast`）。詳細（JSON）を開いて見られる
- [ ] 英語と日本語の表示を、ブラウザの言語設定で切り替える
- [ ] 説明サイトと GitHub へのリンク（変更: 旧版はヘッダーに GitHub のアイコン。sfbench はヘッダーの「?」で説明サイト、設定画面の下部に両方）

## 引き継がない機能

- ログイン画面、ログアウト、ようこそ画面: sf CLI の認証を使うため不要。組織の切り替えに置き換える。
- ログイン中のユーザー名の表示: 組織の切り替えボタンにエイリアスと種別を出す。
- PWA（Service Worker）: ローカルのサーバーで動くため不要。
- Google Analytics: ローカルのツールで、外部に利用状況を送る理由がない。
