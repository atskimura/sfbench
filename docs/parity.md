# lwc-soql-builder の機能の引き継ぎ

lwc-soql-builder の機能を、sfbench で実装したかどうかを管理する一覧である。
旧版のコード（lwc-soql-builder の `src/modules/cmp/` と `src/modules/store/`）から洗い出した。
実装したら `[x]` にする。
「（新規）」は旧版になく sfbench で足す機能、「（変更）」は旧版から振る舞いを変える機能である。
引き継がない機能は末尾に理由とともに書く。

## オブジェクトの一覧（旧版 `sobjectsPanel`）

- [x] 組織のオブジェクトをラベルと API 名で一覧する
- [x] ラベルまたは API 名の一部で絞り込む
- [x] 絞り込みの文字をクリアするボタン
- [x] オブジェクトを選ぶと、項目の一覧に切り替わり、エディタに `SELECT Id FROM <オブジェクト>` が入る
- [x] 一覧を再読み込みする（新規）

## 項目の一覧（旧版 `fieldsPanel`、`fieldsTree`）

- [x] オブジェクトの一覧に戻るボタン
- [x] 「Fields」と「Child Relationships」のタブ
- [x] ラベルまたは API 名の一部で絞り込む。絞り込みは最上位の項目だけに効く。クリアするボタン
- [x] 各項目に、ラベル、API 名、型を表示する
- [x] メニュー: すべての項目を選ぶ（SELECT 句を項目の一覧で置き換え、親の項目とサブクエリは消える）、すべての選択を外す（`Id` だけにする）、API 名の昇順、降順で並べる
- [x] 項目を押すと SELECT 句に追加、もう一度押すと外す
- [x] 参照項目を展開して、親オブジェクトの項目を選ぶ。親をたどれるのは5階層まで（SOQL の制限）で、それを超えると案内を出す
- [x] ポリモーフィックな参照項目は、参照先の最初のオブジェクト（`referenceTo[0]`）だけを展開する（旧版の仕様をそのまま引き継ぐ）
- [x] 項目を再読み込みする（新規）

## 子リレーションの一覧（旧版 `relationshipsTree`）

- [x] 子リレーションを、子オブジェクトの API 名とラベルと一緒に一覧する
- [x] 絞り込む
- [x] 子リレーションの名前を押すと、`(SELECT Id FROM <リレーション>)` のサブクエリを追加する。もう一度押すと外す
- [x] 子リレーションを展開して、その項目をサブクエリに追加する

## エディタ（旧版 `queryEditorPanel`）

- [x] SOQL を書くエディタ
- [x] 項目名、オブジェクト名、リレーション名は大文字と小文字を区別せずに照らし合わせる（変更: 旧版は区別していた）
- [x] 項目を押したときに SOQL を解析できなければ、エディタを書き換えずに案内する（変更: 旧版は直前に解析できた内容で上書きしていた）
- [x] エディタの SOQL を解析できると、項目の一覧の選択状態が追従し、左の一覧が FROM のオブジェクトに切り替わる。エディタを空にすると、オブジェクトの一覧に戻る（旧版 `UPDATE_SOQL`）
- [x] 実行（Query）
- [x] 削除済みも含めて実行（Query All）
- [x] 整形（Format SOQL）
- [x] 補完: 項目を API 名またはラベルで探して挿入する。挿入する名前からは名前空間を省く（名前空間を省く設定がオンのとき）
- [x] 補完: SOQL のキーワードを挿入する
- [x] 補完は入力に合わせて開くほか、Ctrl+Space でも開く。↑↓、Enter、Esc、クリックで操作する
- [ ] 日本語入力の変換を確定した Enter で補完を開く。変換中の Enter で補完の候補を確定しない
- [x] 補完: カーソルの位置に応じて候補を変える。FROM のあとはオブジェクト、`Account.` のあとは参照先の項目、サブクエリの中は子オブジェクトの項目（新規）
- [x] 管理パッケージの名前空間を省略して書ける（`Sforce-Call-Options: defaultNamespace`）。SOQL の生成と補完で名前空間を省く。一覧の表示は名前空間付きのまま
- [x] 名前空間を省く機能を、設定でオフにできる（新規）
- [x] Tooling API で実行する（新規）

## 最近のクエリ（旧版 `queryListPanel`）

- [x] 実行に成功したクエリを新しい順に残す。同じクエリは先頭に移す（変更: 旧版は全組織共通で20件、sfbench は組織ごとに100件）
- [x] 押すとエディタに読み込む。読み込むと、エディタの書き換えと同じく左の一覧が切り替わる
- [ ] AI に頼んだ文をクエリと一緒に表示する（新規、区切り3）

## 結果（旧版 `outputPanel`、`outputTable`、`outputCell`）

- [x] 総件数を表示する
- [x] 列は、SELECT 句ではなく、取得した全レコードのキーを集めて作る。親リレーションの項目は `Account.Name` のような列に展開する。集計関数の `expr0` などにも対応する
- [x] 子リレーションのセルには件数を表示し、押すと子レコードの表を開く。閉じるボタン。新しく実行すると子レコードの表は閉じる
- [x] スクロールに合わせて行を追加で描画し（旧版は200行ずつ）、続きのページ（`nextRecordsUrl`）を取得する
- [x] 18桁のレコード ID を Salesforce のレコードへのリンクにする
- [x] ヘッダーの「組織を開く」ボタンで、ログイン済みの状態で組織を開く（新規）
- [x] 結果の行を絞り込む（新規）
- [x] CSV 出力。続きのページも全件取得し、BOM 付きで、カンマ、改行、二重引用符を含む値を引用符で囲む。ファイル名は `<オブジェクト>.csv`。子リレーションのセルは件数（`N rows`）を出力する
- [x] 実行エラーを表示する

## 全体

- [x] API 使用量を表示する
- [x] 読み込み中の表示
- [x] エラーの通知（旧版 `toast`）。詳細（JSON）を開いて見られる
- [x] 英語と日本語の表示を、ブラウザの言語設定で切り替える
- [x] 説明サイトと GitHub へのリンク（変更: 旧版はヘッダーに GitHub のアイコン。sfbench はヘッダーの「?」と設定画面の下部。0.1.0 では GitHub の README を開く）

## 引き継がない機能

- ログイン画面、ログアウト、ようこそ画面: sf CLI の認証を使うため不要。組織の切り替えに置き換える。
- ログイン中のユーザー名の表示: 組織の切り替えボタンにエイリアスと種別を出す。
- PWA（Service Worker）: ローカルのサーバーで動くため不要。
- Google Analytics: ローカルのツールで、外部に利用状況を送る理由がない。
